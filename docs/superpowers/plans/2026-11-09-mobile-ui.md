# Mobile UI Implementation Plan

> **For agentic workers:** Implement independent join, question and results presentation tasks in parallel; integrate and review the whole change before completion.

**Goal:** Apply the approved mobile visual direction to joining, trivia gameplay and results.

**Architecture:** Scoped mobile tokens and presentation components wrap existing session behaviour. Keep protocol and fair-play logic unchanged; validate optional result data at the UI boundary.

**Tech Stack:** Expo 56, React Native 0.85, TypeScript, expo-font, expo-image.

**Spec:** ../specs/2026-11-09-mobile-ui-design.md

## Global constraints
- Phun Party branding; nine-character authenticated joining.
- No fabricated scores/timers or unsupported rematch calls.
- No desktop/shared-display changes or user screen access.
- Preserve all live session and fair-play behaviour.

## Review focus
- Manual joining remains available after denied camera permission.
- Repeated joins, invalid codes and failed requests recover coherently.
- Long text and large font settings keep question controls reachable.
- Selected, submitted, frozen and waiting states remain distinct.
- Missing/malformed final scores and ties cannot produce false winners.
